# Security

## Reporting a vulnerability

Please report security issues privately to **support@norman.finance** with
"Security" in the subject, not in a public issue or pull request.

Include what you found, how to reproduce it and the impact you expect. If you
used a Norman account for testing, tell us which one. Do not access, change or
keep data that is not yours, and do not run load or denial-of-service tests.

We confirm receipt and keep you updated until the issue is resolved.

## Scope

- The hosted MCP server at `https://mcp.norman.finance`, including its OAuth
  endpoints.
- The skills and client manifests in this repository.
